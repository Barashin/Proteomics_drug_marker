1000 ps以降は安定なタンパク質構造だと仮定して、2000 ps付近のpdbファイルを抽出していきます。

```
gmx trjconv -s md_0_1.tpr -f md_0_1.xtc -o frame_2ns.pdb -dump 2000
```

シミュレーションの座標データから、2ns時点（2000 ps）の構造を抽出し、PDBファイルとして保存する。

- `s md_0_1.tpr` → **構造情報を含むトップファイル（`md_0_1.tpr`）を指定。**
- `f md_0_1.xtc` → **シミュレーションのトラジェクトリ（`md_0_1.xtc`）を指定。**
- `o frame_2ns.pdb` → **出力ファイル（2000 ps時点の構造を`frame_2ns.pdb`に保存）。**
- `dump 2000` → **2000 ps（=2 ns）時点のフレームを抽出。**

```bash
align frame_2ns.pdb, original.pdb
```
