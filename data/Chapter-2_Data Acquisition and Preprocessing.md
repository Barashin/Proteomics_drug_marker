# **Data Acquisition and Preprocessing**

# **2.1 Public DIA Proteomics Data Download:**

This section explains how to locate, access, and download the public DIA proteomics dataset used in the reference study.

## **2.1 i) Locating the Dataset in ProteomeXchange**

ProteomeXchange ([https://www.proteomexchange.org](https://www.proteomexchange.org))/ is a global consortium that provides public access to mass spectrometry–based proteomics datasets. To begin data acquisition, users should visit the ProteomeXchange website [(https://proteomecentral.proteomexchange.org/ui?view=datasets](https://proteomecentral.proteomexchange.org/ui?view=datasets)) and use the search bar to locate the dataset referenced in the study. In this example, the dataset identifier PXD058672 is entered into the search field (highlighted in red). Once the dataset appears in the results list, users can click on the dataset ID to access detailed information about the study and its associated files.

## **2.2 ii) Selecting the Dataset from Search Results**

After searching for the dataset ID, the dataset appears in the ProteomeXchange results table. Users should click directly on the highlighted dataset row corresponding to PXD058672. This action redirects the user to the dataset overview page, where detailed metadata, repository information, and file access options are available.

## **2.3 iii) Dataset Overview and Metadata Page**

The dataset overview page provides essential metadata, including the study title, experimental description, species, instrument type, and hosting repository. In this case, the dataset is hosted by **jPOSTrepo**, a ProteomeXchange partner repository. Reviewing this page allows users to verify that the dataset matches the referenced publication before proceeding to download the data.

## **2.4 iv) Accessing the Files Tab in jPOSTrepo**

From the dataset overview page, users should locate and click the **“Files”** tab (highlighted in red). This tab contains all raw and processed data files associated with the study. The Files section lists individual DIA raw files, converted mzML files, and processed results generated using DIA-NN.

## **2.5 v) Downloading Data Files (Bulk or Individual)**

Within the Files section, users have two download options.

* To download the **entire dataset at once**, click the **“Download all”** button (highlighted in red), which downloads all files as a single archive (\~38.74 GB).

* To download **individual files**, users can click the **“Detail”** button next to each file. This option is useful when only specific samples or file types (e.g., mzML or DIA-NN result files) are required.

# **2.2 Scope:**

## **2.1 i) Scope of this Chapter**

This chapter focuses exclusively on **public DIA proteomics data acquisition** using the dataset referenced in the selected research article. It explains **how to locate the dataset in ProteomeXchange**, access the **hosting repository (jPOSTrepo)**, and **download the available data files** using both **web browser–based** and **bulk download** methods.
