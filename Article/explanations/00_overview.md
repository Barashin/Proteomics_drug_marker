# DIA-MSプロテオミクス解析パイプライン 全体概要

## このパイプラインの目的

Toyota et al. 2025の大腸がんプロテオミクス論文を**3つの異なる手法**で再現・拡張し、タンパク質レベルでのがん関連バイオマーカーを発見することを目指します。

**3つの手法**：
1. **Sage**: 商用利用可能な理論スペクトル検索（MIT ライセンス）
2. **OpenMS + AlphaPeptDeep**: 深層学習ベースの高精度DIA解析
3. **DIA-NN**: 論文標準手法（商用利用制限あり）

## プログラミング初学者の方へ

このプロジェクトは「**コピペで動く**」ことを重視して設計されています。
- 各ステップの**入力と出力**を明確化
- 専門用語は**すべて定義付き**で解説
- **なぜその処理が必要か**の根拠を併記

## 全体の処理フロー

```
【Step 1-3: データ準備】
ProteomeXchange からRAWデータ取得 → mzML変換・検査

【Step 4: タンパク質同定・定量】
┌─ Sage解析 ─────────┐  ┌─ OpenMS深層学習 ────┐
│ step_04_sage.py   │  │ step_05_openms.py  │
│ ↓                 │  │ ↓                  │
│ 2,110タンパク質    │  │ 19,981タンパク質    │
└───────────────────┘  └─────────────────────┘
              ↓
【Step 5-8: 統計解析・可視化】
前処理 → 相関・PCA → 差分発現 → COSMIC照合 → ステージ解析
```

## 重要な概念（このプロジェクトで学べること）

### データサイエンス
- **欠損値処理**: 生物学データ特有の欠損パターンへの対応
- **正規化・標準化**: データを比較可能にする前処理
- **主成分分析（PCA）**: 高次元データの可視化
- **クラスタリング**: サンプルのグルーピング

### 統計解析
- **t検定**: 2群間の平均値比較
- **多重検定補正**: 偽陽性率のコントロール
- **効果量**: 統計的有意性vs実用的重要性
- **ANOVA**: 3群以上での分散分析

### バイオインフォマティクス
- **DIA-MS**: Data-Independent Acquisition質量分析
- **プロテオミクス**: タンパク質の網羅的解析
- **バイオマーカー**: 疾患の指標となるタンパク質
- **COSMIC**: がん関連遺伝子データベース

### 機械学習・深層学習
- **理論スペクトル予測**: 深層学習による質量分析予測
- **保持時間予測**: クロマトグラフィー予測モデル
- **Transformer**: 自然言語処理技術のプロテオミクス応用

## このプロジェクトの技術的意義

### 商用利用可能なプロテオミクス解析
論文では商用利用に制限のあるDIA-NNを使用していますが、本プロジェクトでは **MIT/BSD/Apache 2.0 ライセンス** のツールのみを使用し、**企業・受託・商用サービスで制約なく利用可能** です。

### 深層学習による性能向上
OpenMS + AlphaPeptDeep による深層学習アプローチで、**論文の1.9倍のタンパク質検出**（19,981 vs 10,329）を実現しました。

### 教育的価値
複雑なプロテオミクス解析を**初学者でも理解できる形**で実装し、バイオインフォマティクス教育のリソースとして活用できます。
