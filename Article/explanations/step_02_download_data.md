# step_02_download_data.py の解説

## このコードの役割

Toyota et al. 2025論文の**公開データをインターネットから自動取得**し、プロテオミクス解析に必要なファイルを `data/raw/` ディレクトリにダウンロードするスクリプトです。

## 全体フロー

```
インターネット接続確認 → ダウンロード先準備 → 論文補足データ取得 → UniProtデータベース取得 → 完了
```

| | ファイル | 内容 |
|-|---------|------|
| **入力** | インターネット接続 | 必要（プロキシ環境では設定が必要な場合あり） |
| **出力** | `data/raw/proteomes-13-00038-s001.zip` | 論文の補足データ（18個のExcelファイル） |
| **出力** | `data/raw/human_proteome.fasta.gz` | ヒトプロテオーム配列データベース |
| **出力** | `data/raw/human_proteome.fasta` | 解凍済み配列データベース |

**所要時間の目安**: 30分〜1時間（インターネット回線速度による）

## セクション別解説

### セクション1: ライブラリの読み込み

```python
import os        # ファイルパス操作・ディレクトリ作成に使用
import requests  # HTTPリクエスト（ファイルのダウンロード）に使用
import sys       # Pythonのバージョン確認等に使用
```

**目的**: ファイルダウンロードとパス操作に必要なライブラリを準備

**主要な関数・ライブラリ**:

| 名前 | 役割 |
|------|------|
| `os.path.join` | OS依存しないファイルパス作成（Windows/Mac/Linux対応） |
| `requests.get` | HTTPでファイルをダウンロード（ブラウザと同じ仕組み） |
| `os.makedirs` | ディレクトリを階層的に作成 |

**つまずきやすいポイント**:

- **パス区切り文字**：Windows は `\`、Mac/Linux は `/` だが、`os.path.join()` で自動対応
- **プロキシ環境**：企業ネットワークでは `requests` にプロキシ設定が必要な場合あり
- **ファイアウォール**：HTTPSポート(443)がブロックされているとダウンロード失敗

### セクション2: ダウンロード先の準備

```python
SCRIPT_DIR = os.path.dirname(os.path.abspath(__file__))
DATA_DIR = os.path.join(SCRIPT_DIR, "..", "data", "raw")
os.makedirs(DATA_DIR, exist_ok=True)
```

**目的**: データ保存先ディレクトリを作成（存在しない場合）

**引数の意味**:

- `__file__`: このスクリプト自身のパスを表す特殊変数
- `os.path.abspath()`: 相対パスを絶対パス（フルパス）に変換
- `exist_ok=True`: ディレクトリが既に存在してもエラーにしない

**なぜこの設計か**:
プロジェクトのどのディレクトリからスクリプトを実行しても、常に正しい場所（`data/raw/`）にファイルが保存されるようになっています。

### セクション3: 論文補足データのダウンロード

```python
SUPP_URL = "https://mdpi-res.com/d_attachment/proteomes/proteomes-13-00038/article_deploy/proteomes-13-00038-s001.zip"
```

**目的**: 論文のSupplementary Tablesを一括ダウンロード

**URLの構造**:
- `mdpi-res.com`: MDPI出版社のリソースサーバー
- `proteomes-13-00038`: 論文ID（Proteomes誌の2025年第13巻3号38番目論文）
- `s001.zip`: 補足資料のZIPファイル（18個のExcelファイルを含む）

**なぜZIPファイルか**:
個別にExcelファイル18個をダウンロードするより、1回のダウンロードで済むため効率的です。

### セクション4: UniProtプロテオームデータベースの取得

```python
UNIPROT_URL = "https://rest.uniprot.org/uniprotkb/stream?compressed=true&format=fasta&query=proteome%3AUP000005640"
```

**目的**: ヒトの全タンパク質配列データベースを取得

**URLパラメータの意味**:

| パラメータ | 値 | 意味 |
|-----------|---|------|
| `format=fasta` | FASTA形式 | タンパク質配列の標準フォーマット |
| `compressed=true` | gzip圧縮 | ダウンロードサイズを1/3程度に圧縮 |
| `proteome:UP000005640` | ヒト参照プロテオーム | 約20,000タンパク質を収録 |

**FASTA形式とは**:
```
>タンパク質ID | 説明
アミノ酸配列（1文字表記）
>次のタンパク質ID | 説明
次のアミノ酸配列
```

## 【深掘り】 ProteomeXchangeとは？

- **ひとことで**: プロテオミクスデータの国際的な公開リポジトリ
- **定義**: 質量分析による実験データ（RAWファイル）と解析結果を研究者が公開・共有するためのデータベースネットワーク
- **どんなとき使う**: 論文で報告されたプロテオミクス実験を再現したい時、メタ解析を行いたい時
- **アクセサリ番号**: PXD058672のように一意のIDが付与され、論文に記載される
- **参考**: Toyota et al. 論文の Materials and Methods セクション "Data Availability"

## 【深掘り】 UniProtとは？

- **ひとことで**: 世界最大のタンパク質配列・機能情報データベース
- **定義**: Swiss-Prot（手動キュレーション）とTrEMBL（自動アノテーション）で構成される包括的なタンパク質情報リソース
- **使いどころ**: DIA-MSでタンパク質を同定する際の「答え合わせ」用データベース
- **参照プロテオーム**: 各生物種の代表的なタンパク質セット（ヒトの場合は約20,000種類）
- **なぜ必要**: 質量分析で得られたペプチド断片から元のタンパク質を特定するため

## よくある質問

**Q: ダウンロードが途中で止まってしまいます**
A:
1. インターネット接続を確認してください
2. 企業ネットワークの場合、プロキシ設定が必要な場合があります
3. ファイルサイズが大きい（UniProtは約50MB）ため、安定した回線での実行をお勧めします

**Q: "403 Forbidden" エラーが出ます**
A:
1. MDPIサーバーが一時的にアクセス制限をかけている可能性があります
2. 数分待ってから再実行してみてください
3. 論文のウェブページから手動ダウンロードも可能です

**Q: ZIPファイルの中身を確認したい**
A:
```bash
# 解凍せずに中身の一覧を表示
unzip -l data/raw/proteomes-13-00038-s001.zip
```

**Q: 自分のデータで試したい。何を変えればいい？**
A:
1. **URL変更**: `SUPP_URL` を自分の論文のダウンロードURLに変更
2. **生物種変更**: UniProtの `proteome:UP000005640`（ヒト）を別の生物種IDに変更
3. **ファイル名**: 出力ファイル名を適切に変更

**Q: ダウンロードしたデータは何に使われますか？**
A:
- **論文補足データ**: 元論文の解析結果との比較検証に使用
- **UniProtデータベース**: 次のステップ（step_04）でのタンパク質同定に使用
- どちらも解析の精度と再現性確保に不可欠です
