# One-way ANOVA と FDR 補正

## One-way ANOVA とは

**One-way ANOVA (分散分析)** は、**3 群以上の平均値の差**を同時に検定する統計手法です。t 検定は 2 群間しか比較できませんが、ANOVA は任意の群数に拡張できます。

### 帰無仮説と対立仮説

- **帰無仮説 H0**: 全群の平均値は等しい（Normal = Stage II = Stage III）
- **対立仮説 H1**: 少なくとも 1 つの群の平均値が他と異なる

ANOVA の F 統計量は「群間分散 / 群内分散」で、群間の差が群内のばらつきに比べて大きいほど F 値が大きくなります。F 分布から p-value を計算します。

### なぜ3群比較に t 検定を複数回使わないのか

「Normal vs II、Normal vs III、II vs III の 3 回 t検定をすればいい」と思うかもしれませんが、これは **多重検定問題** を引き起こします：

- 1 回の t検定で α = 0.05 なら、偽陽性率 5%
- 3 回独立に検定すると、少なくとも 1 回偽陽性になる確率 = 1 - 0.95³ = 14.3%

ANOVA は全群を一度に検定するので、このような多重性の問題は起きません。

## コード

```python
def anova_per_protein(df, sample_info, clinical_info):
    """各タンパク質について One-way ANOVA を実行。"""
    # ステージごとにサンプルをグループ化
    # Normal: Condition == "Normal"
    # Stage II/III: Condition == "Tumor" かつ clinical_info の Stage 列
    normal_samples = sample_info[sample_info["Condition"] == "Normal"]["Sample"].tolist()
    stage_to_samples = {"Normal": normal_samples}
    for _, row in clinical_info.iterrows():
        stage = row["Stage"]
        if pd.notna(row["Sample_T"]):
            stage_to_samples.setdefault(stage, []).append(row["Sample_T"])

    results = []
    for protein in df.index:
        groups = []
        for stage, samples in stage_to_samples.items():
            values = df.loc[protein, samples].dropna()
            if len(values) >= 2:
                groups.append(values.values)

        # 少なくとも3群で2個以上の有効値が必要
        if len(groups) < 3:
            continue

        # One-way ANOVA
        f_stat, p_value = stats.f_oneway(*groups)

        results.append({
            "Protein": protein,
            "f_stat": f_stat,
            "p_value": p_value,
        })

    de_df = pd.DataFrame(results).set_index("Protein")

    # BH法で FDR 補正
    from statsmodels.stats.multitest import multipletests
    reject, p_adj, _, _ = multipletests(de_df["p_value"], method="fdr_bh")
    de_df["fdr"] = p_adj
    de_df["significant"] = reject

    return de_df
```

### コード詳細

- **`stats.f_oneway(*groups)`**: scipy の ANOVA 関数。`*groups` は複数のグループを位置引数として展開
- **`groups.append(values.values)`**: 各ステージの発現値を numpy 配列にして `groups` リストに追加
- **`len(groups) < 3`**: 3 群比較なので最低 3 群必要
- **`multipletests(..., method="fdr_bh")`**: **Benjamini-Hochberg 法**による FDR 補正
- **`fdr_bh` の戻り値**: `(reject, p_adj, alpha_sidak, alpha_bonf)` のタプル
  - `reject`: 各タンパク質が有意か（FDR 閾値内か）の bool 配列
  - `p_adj`: FDR 補正後の p-value（q-value とも呼ぶ）

## Benjamini-Hochberg (BH) 法とは

多数の仮説検定を同時に行うとき、**偽陽性の割合を制御する**手法です。

### 手順

1. 全タンパク質の生 p-value を昇順にソート
2. i番目のタンパク質について `adjusted_p[i] = p[i] × N / i` を計算（N は全検定数）
3. 閾値 α (例: 0.01) を下回る最大の i までを有意とする

### 意味

生 p-value 0.01 の閾値で 2,381 タンパク質を検定すると、**単純計算で約 24 個の偽陽性** が出ます。BH 補正はこれを統計的に制御し、「有意とされたタンパク質のうち、平均して 1% は偽陽性」という保証を与えます。

- **検定対象**: 2,381 タンパク質
- **FDR < 0.01 で有意**: **13 個**

### なぜ 13 個と少ないのか

論文がこの解析で示した「Cluster 14 = 1,324 個」と比べて 13 個は非常に少ないです。理由：

1. **ステージ数が 3 群のみ**（Normal, II, III）で、連続性が捉えにくい
2. **各ステージのサンプル数が少ない**（Stage II = 4、Stage III = 4）
3. **FDR < 0.01 の厳しい閾値**
4. **論文はステージ別中央値で 30 クラスター** に分けてからパターンマッチするという別手法を使っている（第9章 9-2 節で解説）

実際には論文も「ANOVA で全タンパク質を検定」という手順を取っているわけではなく、「Figure 2 の差分発現タンパク質（2,642）を 30 クラスターに階層分割し、それぞれのパターンを解釈」という段取りです。本書のスクリプトは両者のハイブリッド（ANOVA + クラスタリング）を実装しています。
