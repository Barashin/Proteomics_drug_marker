# Top N タンパク質の解析

## 論文 Figure 2 の狙い

論文の Figure 2 は、「**少数のトップ遺伝子だけでも Normal/Tumor を完全に分離できる**」ことを示すためのパネルです：

| パネル | 対象 | 意味 |
|-------|------|------|
| Figure 2a | 全有意差タンパク質（論文: 2642） | 全体のヒートマップ |
| Figure 2b | 同上 | 全体の PCA |
| Figure 2c | Top 50（↑25 + ↓25） | トップだけで群分離できるか |
| Figure 2d | Top 100（↑50 + ↓50） | 同上、やや増やして |
| Figure 2e | Top 200（↑100 + ↓100） | 同上、さらに増やして |
| Figure 2f-h | Top 50/100/200 の PCA | PCA でも分離するか |

本書もこの構成に従って、全有意差タンパク質（954個）、Top 50/100/200 それぞれについて **ヒートマップ + PCA** を描画します。

## Top N の選び方

発現差の大きさで順位をつけ、上位から N/2 ずつ Up と Down から取ります：

```python
def top_n_proteins(de_results, n):
    """fold changeの絶対値上位 n/2 ずつ（Up/Down各）を取る。"""
    up = de_results[de_results["significant"] == "Up"].copy()
    down = de_results[de_results["significant"] == "Down"].copy()

    # fold change の絶対値で降順ソート
    up_sorted = up.sort_values("log2_fc", ascending=False)
    down_sorted = down.sort_values("log2_fc", ascending=True)

    half = n // 2
    top_up = up_sorted.head(half).index.tolist()
    top_down = down_sorted.head(half).index.tolist()
    return top_up + top_down
```

## 本書データでの Top N 構成

実際に走らせると、Down 側のタンパク質が 199 個しか存在しないため、**Top 200 (各 100 個ずつ)** を要求したときに Down が 100 まで届かず 199 個になります。本書のログを見ると：

```
（上昇50 + 低下50 = 合計100 タンパク質）
（上昇100 + 低下100 = 合計200 タンパク質）
（上昇200 + 低下199 = 合計399 タンパク質）  ← Downは199で頭打ち
```

最後の Top 200 行は実質 **Top 400** 相当（↑200 + ↓199）になっています。スクリプトはこれを自動的に処理し、可能な範囲で指定数を満たすようにしています。

## 実装のポイント

```python
def plot_topn_analysis(df, de_results, top_n_list=[50, 100, 200]):
    """Top N タンパク質それぞれについてクラスタリングとPCAを描画。"""
    for n in top_n_list:
        proteins = top_n_proteins(de_results, n)
        sub = df.loc[proteins]

        # クラスタリングヒートマップ
        g = sns.clustermap(
            sub, cmap="RdBu_r", method="ward", metric="euclidean",
            z_score=0, col_colors=colors, figsize=(10, 10),
        )
        g.savefig(f"fig2{letter_cluster}_clustering_top{n}.png", dpi=300)

        # PCA
        pca = PCA(n_components=2)
        scores = pca.fit_transform(sub.T.values - sub.T.values.mean(axis=0))
        plot_pca(scores, sample_info, f"fig2{letter_pca}_pca_top{n}.png")
```

### ポイント

- **`sub = df.loc[proteins]`**: 選ばれたタンパク質の行だけ抽出（列は全サンプル）
- **`sub.T`**: 転置して PCA 用に「行=サンプル」にする
- **`z_score=0`**: タンパク質ごとに標準化してヒートマップ表示

## 結果の観察ポイント

### 1. 少数のタンパク質でも分離できるか

論文では「Top 50 だけでも Normal/Tumor が PCA 上で完全分離する」ことを強調しています。本書データでも同様の結果が得られるはずです。

ヒートマップでは：

- Top 50: シンプルな2ブロック構造（Normal 7サンプル + Tumor 8サンプル）
- Top 200: より豊かなサブ構造が見える

### 2. Up と Down のバランス

Top 50（↑25 + ↓25）では左右対称ですが、Top 200 は本書データでは Down 側が 199 で頭打ちなので非対称になります。これは「本書の sage 解析では Down 側のタンパク質が相対的に少ない」ためです。

### 3. PCA の寄与率変化

タンパク質数を絞るほど、PC1 寄与率は高くなる傾向があります：

- 全 2,381 タンパク質: PC1 41.5%（第6章）
- 全有意差 954 タンパク質: より高い値
- Top 200: さらに高い値
- Top 50: 最も高い

理由は、「差分が大きいタンパク質だけに絞ると Tumor/Normal の差が相対的に強調される」ためです。

## まとめ

- Top N 解析は「少数の遺伝子でも群分離できるか」を示すための解析
- 本書でも論文の Figure 2 を 8 枚全て再現
- Down 側タンパク質が 199 個しかないため Top 200 は実質 Top 399
- これらの図が「Normal/Tumor の差がトップ遺伝子で説明できる」ことを示す証拠になる
