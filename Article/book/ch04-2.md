# sageの実行とLFQ定量マトリクス構築

この章では、sage の JSON 設定ファイルを作成し、実際に 15 本の mzML ファイルを解析します。続いて sage の出力（ペプチドレベル）を **Gene Symbol × サンプル** のタンパク質マトリクスに集約し、以降の章で使える形式に整えます。

## Step 4-2-1: sage の設定ファイルを作成する

sage は JSON 形式の設定ファイル1つで動作します。論文の DIA-NN パラメータにほぼ揃えた設定を `scripts/sage_config.json` として作成します。

### 設定値の詳細解説

#### `database` セクション — 酵素消化とFASTA

| キー | 値 | 意味 |
|------|---|------|
| `fragment_min_mz` / `fragment_max_mz` | 200 / 1800 | 論文と同じフラグメント m/z 範囲 |
| `peptide_min_mass` / `peptide_max_mass` | 600 / 4000 | ペプチドの質量範囲（precursor m/z 495-865 × charge 2-4 をカバー） |
| `enzyme.missed_cleavages` | 1 | トリプシンが切り損ねる許容回数（論文と同じ） |
| `enzyme.min_len` / `max_len` | 7 / 45 | ペプチド長の範囲（論文と同じ） |
| `enzyme.cleave_at` | `"KR"` | トリプシンは K, R の C 末端側で切断 |
| `enzyme.restrict` | `"P"` | K/R の直後に P が来る場合は切らない（トリプシンの古典ルール） |
| `static_mods.C` | 57.02146 | システイン固定修飾: carbamidomethylation（iodoacetamide由来） |
| `generate_decoys` | true | decoy データベースを自動生成し FDR を計算 |
| `fasta` | `data/raw/human_proteome.fasta` | UniProt human proteome |

#### `quant` セクション — LFQ 定量

| キー | 値 | 意味 |
|------|---|------|
| `lfq` | true | MS1 XIC ベースの LFQ 定量を有効化 |
| `lfq_settings.peak_scoring` | `"Hybrid"` | MS1 形状マッチングと RT 一致の複合スコア |
| `lfq_settings.integration` | `"Sum"` | ピーク強度を合計して統合 |
| `lfq_settings.spectral_angle` | 0.7 | MS1 アイソトープパターン類似度の下限 |
| `lfq_settings.ppm_tolerance` | 10.0 | XIC 抽出時の質量許容（10 ppm、論文と同じ） |
| `lfq_settings.combine_charge_states` | true | 同ペプチドの複数 charge を合算 |

#### ルートレベル — 検索パラメータ

| キー | 値 | 意味 |
|------|---|------|
| `precursor_tol.ppm` | [-10, 10] | precursor 質量許容（論文と同じ 10 ppm） |
| `fragment_tol.ppm` | [-10, 10] | fragment 質量許容（論文と同じ 10 ppm） |
| `precursor_charge` | [2, 4] | precursor の荷電状態範囲（論文と同じ） |
| `deisotope` | false | sage は DIA モードでは deisotoping を無効化推奨 |
| `chimera` | true | DIA の wide isolation window で共溶出する複数ペプチドを許容 |
| `wide_window` | true | **DIA モードを有効化**（precursor_tol を無視して mzML の isolation window を使う） |
| `predict_rt` | false | ここでは false だが、`lfq=true` のとき sage は自動的に true に切り替える |
| `min_peaks` / `max_peaks` | 15 / 150 | 有効とみなすスペクトルのピーク数範囲 |
| `min_matched_peaks` | 4 | PSM として採用するための最低マッチピーク数 |

> **`wide_window: true` が DIA モードのカギ**
> sage は `wide_window: true` を与えると、`precursor_tol` を無視して mzML ファイルに書き込まれている isolation window 情報を直接参照します。本書の mzML は 60 個の isolation window を持ちますが、sage はそれを各スペクトルごとに読み取って、対応する理論ペプチドとマッチングします。

## Step 4-2-2: sage 実行スクリプトを作成する

sage は CLI 単体でも呼べますが、15ファイルの解析を再現可能にするために Python ラッパーを作ります。`scripts/step_04_dia_analysis_sage.py`：

```python
#!/usr/bin/env python3
"""
Step 4: sage によるDIA解析本体
"""
import os, sys, glob, shutil, subprocess, time

SCRIPT_DIR = os.path.dirname(os.path.abspath(__file__))
PROJECT_DIR = os.path.join(SCRIPT_DIR, "..")
CONFIG_PATH = os.path.join(SCRIPT_DIR, "sage_config.json")
MZML_DIR = os.path.join(PROJECT_DIR, "data", "raw", "raw_mzML")
FASTA_PATH = os.path.join(PROJECT_DIR, "data", "raw", "human_proteome.fasta")
OUT_DIR = os.path.join(PROJECT_DIR, "results", "sage_output")


def main():
    sage_bin = shutil.which("sage")
    if sage_bin is None:
        raise SystemExit("sage コマンドが見つかりません")
    mzml_files = sorted(glob.glob(os.path.join(MZML_DIR, "*.mzML")))
    if not mzml_files:
        raise SystemExit(f"No mzML files found in {MZML_DIR}")
    print(f"FASTA: {FASTA_PATH}")
    print(f"mzML files: {len(mzml_files)}")
    os.makedirs(OUT_DIR, exist_ok=True)

    cmd = [
        sage_bin,
        "--fasta", FASTA_PATH,
        "--output_directory", OUT_DIR,
        "--disable-telemetry-i-dont-want-to-improve-sage",
        CONFIG_PATH,
    ] + mzml_files

    t0 = time.time()
    proc = subprocess.Popen(cmd, stdout=subprocess.PIPE,
                            stderr=subprocess.STDOUT, text=True, bufsize=1)
    try:
        for line in proc.stdout:
            sys.stdout.write(line); sys.stdout.flush()
    finally:
        rc = proc.wait()
    elapsed = time.time() - t0
    if rc != 0:
        raise SystemExit(f"sage exited with code {rc}")
    print(f"\n===== sage finished in {elapsed/60:.1f} min =====")


if __name__ == "__main__":
    main()
```

## Step 4-2-3: sage を実行する


## Step 4-2-4: 出力ファイルの確認

`results/sage_output/` 配下に以下のファイルが生成されます：

```
results/sage_output/
├── results.json      (設定パラメータの記録)
├── results.sage.tsv  (PSM テーブル、全同定スペクトル)
└── lfq.tsv           (ペプチドレベル LFQ 定量、15サンプルの列あり)
```

### results.sage.tsv の内容

`results.sage.tsv` は PSM (Peptide-Spectrum Match) 単位のテーブルで、本書の解析では **762,257 行** です。各行には以下の情報が入っています：

| カラム | 説明 |
|-------|------|
| `psm_id` | PSM のユニークID |
| `peptide` | ペプチド配列 |
| `proteins` | UniProt ID（複数ヒット時は `;` 区切り） |
| `filename` | mzMLファイル名 |
| `scannr` | スキャン番号 |
| `charge` | 荷電状態 |
| `peptide_len` | ペプチド長 |
| `hyperscore` | MSFragger系スコア |
| `rt` | 保持時間（秒） |
| `sage_discriminant_score` | 線形判別スコア |
| `spectrum_q` / `peptide_q` / `protein_q` | FDR（q-value） |
| `ms2_intensity` | MS2 フラグメント強度合計 |

### lfq.tsv の内容

`lfq.tsv` はペプチド × サンプルの定量マトリクスで、**27,087 行**、21 列（メタ6列 + サンプル15列）です。

先頭行の例：

```
peptide        charge  proteins                 q_value    score   spectral_angle   CRC04-N.mzML   CRC04-T.mzML  ...  CRC12-T.mzML
GLGTDEDTIIDIITHR  -1   sp|P08133|ANXA6_HUMAN    0.00122    0.815   0.952            94488098.3     92311424.8    ...   ...
DVVIC[+57.02146]PDASLEDAK  -1  sp|Q99497|PARK7_HUMAN  0.00207  0.742  0.925          28403038.6     30122998.1    ...   ...
```

- `charge = -1` は `combine_charge_states: true` により全荷電を統合済みであることを示します
- `q_value` はペプチドレベル FDR。**本書では `q_value < 0.01` でフィルタ**（論文と同じ 1% FDR）
- サンプル列の値はそのペプチドの積分強度（単位: 検出器カウント）

## Step 4-2-5: タンパク質マトリクスへの集約

`lfq.tsv` はペプチドレベルなので、下流の統計解析（t検定、PCA、クラスタリング）で使うには **タンパク質レベルに集約** する必要があります。新しいスクリプト `scripts/step_04_build_protein_matrix.py` を作ります：

```python
#!/usr/bin/env python3
"""
Step 4.5: sage出力からタンパク質定量マトリクスを構築
"""
import os, re
import pandas as pd

SCRIPT_DIR = os.path.dirname(os.path.abspath(__file__))
PROJECT_DIR = os.path.join(SCRIPT_DIR, "..")
LFQ_TSV = os.path.join(PROJECT_DIR, "results", "sage_output", "lfq.tsv")
FASTA = os.path.join(PROJECT_DIR, "data", "raw", "human_proteome.fasta")
OUT_CSV = os.path.join(PROJECT_DIR, "results", "protein_matrix_from_sage.csv")
Q_VALUE_THRESHOLD = 0.01


def build_id_to_gene_map(fasta_path: str) -> dict:
    """UniProt FASTA から accession -> gene symbol の辞書を作る"""
    id_to_gene = {}
    gn_re = re.compile(r"\bGN=([^\s]+)")
    with open(fasta_path) as f:
        for line in f:
            if not line.startswith(">"):
                continue
            header = line[1:].rstrip()
            first_space = header.find(" ")
            id_part = header[:first_space] if first_space > 0 else header
            desc_part = header[first_space + 1:] if first_space > 0 else ""
            parts = id_part.split("|")
            acc = parts[1] if len(parts) >= 3 else id_part
            m = gn_re.search(desc_part)
            gene = m.group(1) if m else (parts[2].split("_")[0] if len(parts) >= 3 else id_part)
            id_to_gene[acc] = gene
    return id_to_gene


def extract_primary_acc(proteins_field: str) -> str:
    first = proteins_field.split(";")[0]
    parts = first.split("|")
    return parts[1] if len(parts) >= 2 else first


def main():
    df = pd.read_csv(LFQ_TSV, sep="\t")
    print(f"読み込み: {len(df)} rows")

    df = df[df["q_value"] < Q_VALUE_THRESHOLD].copy()
    print(f"q_value < {Q_VALUE_THRESHOLD}: {len(df)} peptides")

    meta_cols = ["peptide", "charge", "proteins", "q_value", "score", "spectral_angle"]
    sample_cols = [c for c in df.columns if c not in meta_cols]
    df = df.rename(columns={c: re.sub(r"\.mzML$", "", c) for c in sample_cols})
    sample_cols = [re.sub(r"\.mzML$", "", c) for c in sample_cols]

    df["primary_acc"] = df["proteins"].apply(extract_primary_acc)
    id_to_gene = build_id_to_gene_map(FASTA)
    df["gene"] = df["primary_acc"].map(id_to_gene).fillna(df["primary_acc"])

    matrix = df.groupby("gene")[sample_cols].sum(min_count=1).replace(0, pd.NA).dropna(how="all")
    matrix.index.name = "Protein"
    matrix.to_csv(OUT_CSV)
    print(f"保存: {OUT_CSV} ({matrix.shape[0]} proteins × {matrix.shape[1]} samples)")


if __name__ == "__main__":
    main()
```

### コード詳細

1. **`pd.read_csv(LFQ_TSV, sep="\t")`**: sage の lfq.tsv を読み込み（27,087 ペプチド）
2. **`q_value < 0.01`** でフィルタ: FDR 1% 以下のペプチドのみ残す（結果: **9,042 ペプチド**）
3. **`build_id_to_gene_map`**: FASTA ヘッダの `GN=` フィールドから遺伝子シンボルを抽出
4. **`extract_primary_acc`**: sage の proteins 列（`sp|P12345|NAME;tr|...` 形式）から先頭の accession を取得
5. **`groupby("gene").sum`**: 同じ遺伝子に属するペプチドの強度を合計
6. **`.replace(0, pd.NA).dropna(how="all")`**: 全サンプルで 0/欠損の行を除去
