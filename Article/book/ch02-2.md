# 必要パッケージと動作確認

## Step 2-2-1: パッケージのバージョン確認

仮想環境を有効化した状態で、以下のスクリプトを実行して全パッケージのインストールを確認します。

```bash
micromamba activate crc-proteomics

python -c "
import importlib
packages = {
    'numpy': 'numpy',
    'pandas': 'pandas',
    'scipy': 'scipy',
    'sklearn': 'scikit-learn',
    'matplotlib': 'matplotlib',
    'seaborn': 'seaborn',
    'statsmodels': 'statsmodels',
    'requests': 'requests',
    'openpyxl': 'openpyxl',
}
print('パッケージ確認:')
for import_name, display_name in packages.items():
    try:
        mod = importlib.import_module(import_name)
        ver = getattr(mod, '__version__', 'unknown')
        print(f'  OK: {display_name} ({ver})')
    except ImportError:
        print(f'  NG: {display_name} - 未インストール')
"
```

### 期待される出力

```
パッケージ確認:
  OK: numpy (1.26.4)
  OK: pandas (2.2.1)
  OK: scipy (1.12.0)
  OK: scikit-learn (1.4.1)
  OK: matplotlib (3.8.3)
  OK: seaborn (0.13.2)
  OK: statsmodels (0.14.1)
  OK: requests (2.31.0)
  OK: openpyxl (3.1.2)
```

すべて「OK」と表示されれば成功です。

## Step 2-2-2: 個別パッケージの追加インストール

もし「NG」と表示されたパッケージがある場合、個別にインストールできます：

```bash

# pipでインストール（conda-forgeにない場合）
pip install <パッケージ名>
```

## Step 2-2-4: 簡単なテスト実行

環境が正しくセットアップされたか、簡単なテストを実行します：

```python
#!/usr/bin/env python3
"""環境テスト"""
import numpy as np
import pandas as pd
from scipy import stats
from sklearn.decomposition import PCA
import matplotlib
matplotlib.use('Agg')  # GUIなしで画像生成
import matplotlib.pyplot as plt
import seaborn as sns

# テストデータ作成
np.random.seed(42)
data = np.random.randn(100, 10)
df = pd.DataFrame(data, columns=[f"Sample_{i}" for i in range(10)])

# PCA
pca = PCA(n_components=2)
scores = pca.fit_transform(data)
print(f"PCA寄与率: PC1={pca.explained_variance_ratio_[0]:.3f}, PC2={pca.explained_variance_ratio_[1]:.3f}")

# t-test
t, p = stats.ttest_ind(data[:50, 0], data[50:, 0])
print(f"t-test: t={t:.3f}, p={p:.3f}")

# ヒートマップ生成テスト
fig, ax = plt.subplots(figsize=(6, 4))
sns.heatmap(df.head(20), cmap="RdBu_r", ax=ax)
plt.savefig("test_heatmap.png", dpi=72)
plt.close()
print("ヒートマップ生成: OK (test_heatmap.png)")

print("\n環境テスト完了！すべて正常に動作しています。")
```

このスクリプトを `test_env.py` として保存し、実行します：

```bash
python test_env.py
```

### 期待される出力

```
PCA寄与率: PC1=0.157, PC2=0.131
t-test: t=-0.476, p=0.635
ヒートマップ生成: OK (test_heatmap.png)

環境テスト完了！すべて正常に動作しています。
```

ここまで確認できれば、環境構築は完了です。テスト用ファイルは削除しても構いません：

```bash
rm test_env.py test_heatmap.png
```
