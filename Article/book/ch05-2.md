# 欠損値補完（Perseus互換 downshift法）

## なぜ欠損値を補完するのか

第5章 5-1 節のフィルタリング後、残った 2,381 タンパク質にも、まだ欠損値が存在します。そのまま放置すると、以下の問題が起きます：

- **PCA** は欠損値を扱えない（scikit-learn の PCA は NaN でエラー）
- **階層的クラスタリング** も欠損値があると距離計算に支障
- **t検定** は欠損値を自動除外するが、サンプル数が不揃いになる

そこで、**欠損値を適切に補完する必要があります**。プロテオミクスでは「検出されなかったタンパク質は、存在しないのではなく発現量が低すぎて測定限界以下だった」と解釈するのが一般的です。この解釈に基づく補完方法が **downshift 法**（またの名を「left-censored imputation」）です。

## downshift 法の考え方

各サンプル（列）について：

1. そのサンプルの**有効値の平均 μ と標準偏差 σ** を計算
2. 補完値の中心を **μ − downshift × σ**（下にシフト）
3. 補完値の幅を **width × σ**（元より狭い）
4. この正規分布から欠損値の数だけランダムにサンプリング

パラメータ：

- **downshift = 2.4**: 論文と同じ。有効値の平均より 2.4 SD 下にシフト
- **width = 0.3**: 論文と同じ。元の SD の 30% の幅

### 可視化的な説明

```
         元の有効値分布           補完値の分布
         ─────────                 ─────
         │         │               │   │
         │    μ    │               │   │
         │   σ=2   │               │   │
         ─────────                 ─────
              ↓                       ↓
              ←──── 2.4 × σ ────→
                                   ← 0.3 × σ →
```

補完値は「有効値が広がっている範囲」から約 4.8 単位下（downshift × σ = 2.4 × 2 = 4.8）に、狭く（0.3 × 2 = 0.6 幅）配置されます。

## Step 5-2-1: 補完関数の実装

```python
def impute_missing_values(df, downshift=2.4, width=0.3):
    """Perseus互換の欠損値補完。"""
    df_imputed = df.copy()
    n_imputed = 0

    for col in df.columns:
        valid = df[col].dropna()
        if len(valid) == 0:
            continue

        col_mean = valid.mean()
        col_std = valid.std()

        # 補完値分布のパラメータ
        imp_mean = col_mean - downshift * col_std
        imp_std = width * col_std

        # 欠損値の位置を特定（iloc でインデックス重複問題を回避）
        col_idx = df.columns.get_loc(col)
        col_values = df_imputed.iloc[:, col_idx]
        missing_mask = col_values.isna()
        n_missing = int(missing_mask.sum())

        if n_missing > 0:
            imp_values = np.random.normal(imp_mean, imp_std, n_missing)
            df_imputed.iloc[missing_mask.values, col_idx] = imp_values
            n_imputed += n_missing

    print(f"  欠損値補完: {n_imputed} 値を補完")
    return df_imputed
```

### コード詳細

- **`for col in df.columns`**: サンプル（列）ごとに独立に補完する（サンプル間で補完基準が異なる）
- **`valid = df[col].dropna()`**: そのサンプルの有効値のみ抽出
- **`col_mean` / `col_std`**: 有効値の平均と標準偏差を計算
- **`imp_mean = col_mean - downshift * col_std`**: 補完値の中心位置（有効値平均の2.4σ下）
- **`imp_std = width * col_std`**: 補完値の分布の幅（元の30%）
- **`np.random.normal(imp_mean, imp_std, n_missing)`**: 正規分布から欠損値数分の値を生成
- **`df_imputed.iloc[missing_mask.values, col_idx] = imp_values`**: 欠損位置に補完値を代入

### なぜ `iloc` を使うのか

インデックス（タンパク質名）に重複があった場合、`df[col][missing_mask] = ...` のような代入はエラーになるか、予期せぬ挙動を示します。`iloc` + 整数位置を使うことで、**インデックスに依存しない安全な代入**が実現できます。sage 出力のタンパク質名には通常重複はないですが、安全のための設計です。
