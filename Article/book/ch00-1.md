# 本書の使い方

## 章構成と全体の流れ

本書は15章構成で、DIA-MSプロテオミクス解析を基礎から応用まで段階的に学習できます。

### Phase 1: 基礎理解（第0-1章）
```
第0章: DIA-MSプロテオミクスの世界        【読むだけ、15分】
  ├─ 背景・目的
  ├─ 論文紹介と解析戦略
  └─ 無料ツールへの置き換え戦略
第1章: 環境構築                        【実行30分】
  ├─ Conda環境セットアップ
  ├─ sage-proteomics導入
  └─ Python解析環境構築
```

### Phase 2: データ準備（第2章）
```
第2章: データ取得と理解                  【実行15分】
  ├─ ProteomeXchangeからのダウンロード
  ├─ mzML・FASTAファイル構造理解
  └─ ThermoRawFileParser変換
```

### Phase 3: Sage DIA解析（第3章）
```
第3章: Sage DIA解析 - 基礎編             【実行20分】
  ├─ sage設定ファイル作成
  ├─ DIA検索とタンパク質同定実行
  ├─ 遺伝子マッピングとプロテインマトリクス生成
  └─ タンパク質レベル集約（2,110タンパク質検出）
```

### Phase 4-8: 統計解析とバイオマーカー探索（第4-8章）
```
第4章: データ探索と品質管理              【実行10分】
第5章: 前処理パイプライン               【実行10分】
第6章: 可視化と品質確認                 【実行10分】
第7章: 統計解析 - 差分発現              【実行15分】
第8章: バイオマーカー探索               【実行10分】
  └─ COSMIC照合でがん関連タンパク質22個同定
```

### Phase 9: 深層学習解析（第9章）
```
第9章: OpenMS + 深層学習解析             【実行60分】
  ├─ OpenMSワークフロー概要
  ├─ AlphaPeptDeep深層学習DIA解析
  └─ OpenMS結果処理（19,981タンパク質検出！）
```

### Phase 10-12: 高度な解析（第10-12章）
```
第10章: ステージ別解析                  【実行20分】
第11章: OpenMS統計解析                  【実行20分】
第12章: 手法比較と評価                  【実行15分】
  └─ Sage vs OpenMS 詳細比較（9.5倍の性能差）
```

### Phase 13: 応用と展望（第13章）
```
第13章: 応用と展望                      【読むだけ、10分】
  ├─ 他がん種への応用
  ├─ 深層学習の進歩とプロテオミクス
  └─ 次世代プロテオミクス解析
```

## 読み方のパターン

### 🟢 パターン1: フル体験（推奨・総時間約4時間）

**全章を順番に実行**。DIA-MSプロテオミクスを完全習得できます。
- 対象：プロテオミクス初学者、完全理解したい方
- メリット：最も学習効果が高い、トラブル時の対処能力がつく
- デメリット：時間がかかる、OpenMS部分でリソース消費

### 🟡 パターン2: sage基礎 + 比較（総時間約2時間）

第3-8章（sage解析）+ 第12章（手法比較）を実行。
- 対象：手軽にDIA解析を始めたい方
- メリット：コンパクトで実用的、商用利用可能ツールを重点学習
- デメリット：深層学習の威力を体験できない

### 🔵 パターン3: 深層学習重点（総時間約2時間）

第1-2章（環境・データ準備）→ 第9章（OpenMS深層学習）→ 第12章（比較）
- 対象：最新技術に興味がある方、論文を超える性能を体験したい方
- メリット：最先端技術を習得、圧倒的な検出性能を体験
- デメリット：計算リソース消費、基礎的な理解が浅くなる可能性

### ⚪ パターン4: 統計解析のみ（総時間約1時間）

第4-8章の統計解析部分のみ。事前処理済みデータを使用。
- 対象：プロテオミクスのdry解析手法のみ学習したい方
- メリット：短時間で統計解析スキルを習得
- デメリット：データ取得・前処理の重要性を理解できない

## 2つの実行方法

### 方法1: スクリプト実行（推奨）
```bash
# 単発実行
python scripts/step_03_sage.py

# 一括実行（全パイプライン）
bash scripts/run_all.sh
```

### 方法2: Jupyter Notebook
```bash
# Jupyter起動
jupyter notebook notebooks/

# 対象のnotebookを開いてセルごとに実行
# 例: step_03_sage.ipynb
```

## 推奨システム要件

### 最小構成
- **OS**: Linux/macOS/Windows（WSL2）
- **RAM**: 8GB
- **ストレージ**: 50GB空き容量
- **実行時間**: Sage編 約2時間

### 推奨構成（OpenMS深層学習用）
- **OS**: Linux（Ubuntu 20.04+）
- **RAM**: 16GB以上
- **GPU**: CUDA対応（推奨、なくても実行可能）
- **ストレージ**: 100GB空き容量
- **実行時間**: フル実行 約4時間

## トラブルシューティング

### よくある問題と解決法
1. **環境構築エラー** → 第1章の詳細手順を確認
2. **メモリ不足** → サブセットデータでの実行方法を提示
3. **GPU関連エラー** → CPU版での実行手順を併記
4. **ダウンロード失敗** → 代替取得方法を複数提示

### サポート
各章に「よくあるエラーと対処法」セクションを配置。実際の実行で発生したエラーとその解決法を記載しています。
