# 本書の使い方

## 全体の流れ

本書は以下の順番で進みます。各章は基本的に前の章の結果を使いますが、第3章以降は独立して読むことも可能です。

```
第1章: 論文紹介（読むだけ）
  ↓
第2章: 環境構築（30分程度）
  ↓
第3章: データ取得（10分程度）
  ↓
第4章: sageによるタンパク質同定（計算時間: 約5分）
  ↓
第5章: データ前処理（5分程度）
  ↓
第6章: 全体像の可視化（5分程度）← Figure 1 再現
  ↓
第7章: 差分発現解析（5分程度）← Figure 2 再現
  ↓
第8章: COSMIC照合（5分程度）← Section 3.3 再現
  ↓
第9章: ステージ別解析（5分程度）← Figure 3 再現
  ↓
第10章: まとめと次のステップ
```

## 読み方のパターン

### パターン1: 最初から順番に（推奨）

全章を順番に読みます。初心者はこの方法がおすすめです。

### パターン2: DIA解析ステップをスキップ

第4章で sage を使って mzML から再解析しますが、時間を節約したい読者は `results/protein_matrix_from_sage.csv` をリポジトリから直接利用して第5章から始めることもできます。

### パターン3: 統計解析だけ学びたい

第5-9章のPythonによる統計解析パートだけを読むこともできます。前処理済みのデモデータが自動生成されるので、データ準備なしで始められます。

## ファイル構成

```
Article/
├── environment.yml          # 仮想環境定義（第2章で使用）
├── scripts/                 # 解析スクリプト
│   ├── step_01_download_data.py       # 第3章
│   ├── step_02_preprocess.py          # 第5章
│   ├── step_03_overview_visualization.py  # 第6章
│   ├── step_04_differential_expression.py # 第7章
│   ├── step_05_cosmic_analysis.py     # 第8章
│   ├── step_06_stage_analysis.py      # 第9章
│   └── run_all.sh                     # 一括実行
├── data/raw/                # 入力データ
├── results/                 # 出力結果
│   ├── figures/             # Figure画像
│   └── tables/              # 数値データ（CSV）
├── book/                    # 本書のソースファイル
└── blog/                    # ブログ記事
```

| Python 3.11 | 統計解析・可視化 | PSF (OSS) | - |

| scipy | 統計検定 | BSD (OSS) | Perseus (有料相当) |

| seaborn | ヒートマップ | BSD (OSS) | Python (Seaborn) |
| matplotlib | 可視化 | PSF (OSS) | Python (Matplotlib) |
| statsmodels | 多重検定補正 | BSD (OSS) | Perseus |
| micromamba | パッケージ管理 | BSD (OSS) | - |
