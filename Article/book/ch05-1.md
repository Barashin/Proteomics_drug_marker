# Log2変換と有効値フィルタリング

## Step 5-1-1: 前処理スクリプトを書く

`scripts/step_04_preprocess.py` は、第4章で作成した `protein_matrix_from_sage.csv` を読み込み、Log2変換・フィルタリング・補完を順に適用して `results/preprocessed_data.csv` を出力します。

スクリプトの全体構成は以下の通りです：

```python
#!/usr/bin/env python3
"""Step 2: データ前処理"""
import os
import numpy as np
import pandas as pd

SCRIPT_DIR = os.path.dirname(os.path.abspath(__file__))
PROJECT_DIR = os.path.join(SCRIPT_DIR, "..")
RESULTS_DIR = os.path.join(PROJECT_DIR, "results")

IMPUTATION_DOWNSHIFT = 2.4  # Perseusデフォルト
IMPUTATION_WIDTH = 0.3      # Perseusデフォルト

def load_protein_data(data_dir):
    # results/protein_matrix_from_sage.csv を優先的に読み込み
    sage_matrix = os.path.join(RESULTS_DIR, "protein_matrix_from_sage.csv")
    if os.path.exists(sage_matrix):
        df = pd.read_csv(sage_matrix, index_col=0)

    # (フォールバック略)
```

### コード詳細

- **`IMPUTATION_DOWNSHIFT = 2.4`**: Perseus のデフォルト値と同じ。補完値の中心を、有効値の平均から 2.4 × 標準偏差だけ下にシフトします。「検出されなかった＝発現量が低い」という仮定を反映した値です。
- **`IMPUTATION_WIDTH = 0.3`**: 補完値の分布幅を、元の SD の 30% にします。補完値が「ほぼ同じような低い値」になるようにコントロールします。
- **`VALID_VALUE_RATIO = 0.70`**: 論文と同じ 70% 基準。少なくとも 1 群（Normal or Tumor）で 70% 以上のサンプルに値があるタンパク質のみ残します。

## Step 5-1-2: Log2 変換

```python
def log2_transform(df):
    """生強度を log2 に変換。既に log2 ならスキップ。"""
    median_val = df.median().median()
    if median_val > 100:
        print(f"  Log2変換実行（中央値={median_val:.1f} → 生データと判定）")
        df = np.log2(df.replace(0, np.nan))
    else:
        print(f"  Log2変換スキップ（中央値={median_val:.1f}）")
    return df
```

### なぜ Log2 変換するのか

質量分析の強度値は、低存在量タンパク質で 10^4 程度、高存在量で 10^9 を超えます。5桁以上のダイナミックレンジがあり、**線形スケールで扱うと統計検定の仮定（正規分布）が成立しません**。

Log2 変換を施すと：

- 値の範囲が 10^4〜10^9 → おおよそ 13〜30 に圧縮
- 分布が対数正規 → 正規分布に近づく
- 差分が「倍率」に対応（Log2値の差 1.0 = 2倍の強度差）

このため差分発現解析（第7章）でも、`fold change` を Log2 スケールで計算するのが標準です。

## Step 5-1-3: 有効値フィルタリング

```python
def filter_valid_values(df, sample_groups, ratio=VALID_VALUE_RATIO):
    """少なくとも1群で指定割合以上の有効値を持つタンパク質のみ残す。"""
    keep_mask = pd.Series(False, index=df.index)
    for group_name, samples in sample_groups.items():
        group_data = df[samples]
        valid_ratio = group_data.notna().sum(axis=1) / len(samples)
        keep_mask |= (valid_ratio >= ratio)
    return df[keep_mask]
```

### コード詳細

- `group_data.notna().sum(axis=1)`: 各タンパク質について有効値（NaNでない値）の個数をカウント
- `/ len(samples)`: それを群のサンプル数で割って割合に変換
- `>= ratio`: 閾値（0.70）以上かをチェック
- `keep_mask |= ...`: いずれか1群でも閾値を満たせば True（論理和）

### なぜ「いずれか1群で70%」なのか

この設計には重要な意味があります。もし「**全**群で70%以上」を要求すると、**Normal でのみ発現し Tumor では検出されないタンパク質（腫瘍抑制因子など）が除外**されてしまいます。

- 例: NAGLU は Normal 7サンプル中7つで検出、Tumor 8サンプル中2つで検出
  - 「いずれか1群で70%以上」→ Normal で 7/7 = 100% なのでOK → **残る**
  - 「全群で70%以上」→ Tumor で 2/8 = 25% なのでNG → **除外**

後者だと、Normal/Tumor 間の差が最大（つまり生物学的に最も興味深い）タンパク質を見逃してしまいます。**論文の「いずれか1群で70%」は、生物学的に意味のあるタンパク質を残すための設計**です。
