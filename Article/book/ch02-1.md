# micromambaとPython環境

## micromambaとは

**micromamba**は、conda互換の軽量パッケージマネージャです。condaと同じリポジトリ（conda-forge, bioconda等）からパッケージをインストールできますが、condaよりも**高速で軽量**です。

| 項目 | conda | micromamba |
|------|-------|-----------|
| 速度 | 遅い | **高速** |
| サイズ | 大きい | **軽量（数MB）** |
| 互換性 | - | conda互換 |
| 仮想環境 | 対応 | 対応 |
| ライセンス | BSD | BSD |

## Step 2-1-1: micromambaのインストール

### macOS / Linux

ターミナルを開き、以下のコマンドを実行します：

```bash
"${SHELL}" <(curl -L micro.mamba.pm/install.sh)
```

インストール中にいくつか質問されますが、すべてデフォルト（Enter）で問題ありません。

### コード詳細

- `"${SHELL}"`: 現在使用しているシェル（bash or zsh）でスクリプトを実行
- `<(curl -L ...)`: URLからインストールスクリプトをダウンロードして実行
- `micro.mamba.pm/install.sh`: micromamba公式のインストールスクリプト

### Windows（WSL2）

Windows の場合、まずWSL2（Windows Subsystem for Linux）をセットアップしてから、上記と同じコマンドを実行します。

```powershell
# PowerShellで実行
wsl --install
```

WSLが起動したら、Ubuntu ターミナルで同じコマンドを実行してください。

### インストール確認

```bash
micromamba --version
```

バージョン番号が表示されれば成功です。

## Step 2-1-2: 仮想環境の作成

プロジェクト用の仮想環境を作成します。`environment.yml` ファイルを使って、必要なパッケージを一括でインストールします。

### environment.yml の作成

プロジェクトのルートディレクトリに移動し、以下の内容で `environment.yml` を作成します。本書のリポジトリにはすでに含まれています。

```yaml
name: crc-proteomics
channels:
  - conda-forge
  - bioconda
dependencies:
  - python=3.11
  - pip
  - numpy>=1.24
  - pandas>=2.0
  - scipy>=1.11
  - scikit-learn>=1.3
  - matplotlib>=3.7
  - seaborn>=0.13
  - statsmodels>=0.14
  - requests>=2.31
  - openpyxl>=3.1
  - adjustText>=0.8
  - pip:
    - gseapy>=1.0
```

### コード詳細

- `name: crc-proteomics`: 仮想環境の名前。好きな名前に変更可能
- `channels`: パッケージのダウンロード元
  - `conda-forge`: 科学計算パッケージの最大リポジトリ
  - `bioconda`: バイオインフォマティクス専用リポジトリ
- `dependencies`: インストールするパッケージ一覧
  - `python=3.11`: Python本体（バージョン3.11を指定）
  - `numpy`, `pandas`: データ操作（PerseusのPython代替）
  - `scipy`: 統計検定（Welch's t-test, ANOVA）
  - `scikit-learn`: PCA（主成分分析）
  - `seaborn`, `matplotlib`: 可視化（ヒートマップ等）
  - `statsmodels`: 多重検定補正（FDR）
  - `openpyxl`: Excelファイル読み込み（補足データ用）

### 環境の作成と有効化

```bash
# 環境を作成（初回のみ。5-10分程度）
micromamba create -f environment.yml -y

# 環境を有効化（毎回必要）
micromamba activate crc-proteomics
```

### コード詳細

- `create -f environment.yml`: YAMLファイルの定義に従って環境を作成
- `-y`: 確認プロンプトを自動でYes
- `activate crc-proteomics`: 作成した環境を有効化。プロンプトの先頭に `(crc-proteomics)` が表示されます

### よくあるエラー

| エラー | 原因 | 対処 |
|--------|------|------|
| `micromamba: command not found` | PATHが通っていない | ターミナルを再起動 |
| `Could not solve for environment specs` | パッケージの競合 | バージョン指定を `>=` に緩める |
| `CondaHTTPError` | ネットワーク接続の問題 | プロキシ設定を確認 |
