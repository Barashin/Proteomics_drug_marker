## Figure 1 の目的

論文の Figure 1 は、Normal/Tumor 2 群のプロテオームが **全体として** どれくらい似ているか／違うかを、3 つの異なる角度から可視化したものです。

| パネル | 手法 | 見るもの |
|-------|------|---------|
| Figure 1a | Pearson相関ヒートマップ | サンプル同士の類似度（ペアごと） |
| Figure 1b | 階層的クラスタリング | サンプルのクラスター構造（木構造） |
| Figure 1c | PCA | 高次元データの低次元投影（2D 散布図） |

いずれも「Normal 同士、Tumor 同士は似ていて、Normal と Tumor は分離する」ことを示すためのサニティチェックです。

## 本書での再現結果（プレビュー）

実際のスクリプト実行結果の要点：

| パネル | 論文の結果 | 本書の結果 (sage + 15ファイル) |
|-------|-----------|----------------------------|
| 相関値 (Pearson r) | 0.744 – 0.982 | 0.70 – 0.93 |
| PCA PC1 寄与率 | 42.1% | **41.5%** |
| PCA PC2 寄与率 | 10.8% | **17.4%** |
| PC1 + PC2 合計 | 52.9% | 58.9% |
| Normal/Tumor 分離 | 明確に分離 | 明確に分離 |

PC1 寄与率が論文（42.1%）とほぼ同じ **41.5%** になった点は特に重要です。これは **Tumor と Normal の違いが PC1 という1つの主成分でほぼ説明できる**ことを意味し、「腫瘍化による系統的なプロテオーム変動」が本書のデータでも再現されていることを示しています。

## スクリプト `step_05_overview_visualization.py`

この章の全処理は、1本のスクリプト `scripts/step_05_overview_visualization.py` で実行します。内部では以下の手順で3つの図を生成します：

1. `results/preprocessed_data.csv` を読み込み
2. Pearson 相関行列を計算 → ヒートマップで可視化（Figure 1a）
3. 階層的クラスタリング（Ward法）→ 樹形図 + ヒートマップ（Figure 1b）
4. PCA で PC1–PC2 に投影 → 散布図（Figure 1c）

```bash
micromamba run -n crc-proteomics python scripts/step_05_overview_visualization.py
```
