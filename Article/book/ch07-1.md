# Welchのt検定

## Welch's t-test とは

**Welch の t検定**は、**2群の分散が等しいと仮定しない**独立2標本 t検定です。通常の Student's t-test は「2群の分散は等しい」という強い仮定を置きますが、Welch's t-test はこの仮定を緩めているため、**サンプルサイズや分散が群間で異なる場合でも適用可能**です。

プロテオミクスでは、Normal と Tumor でサンプル数が同じとは限らず、分散も異なることが多いため、**Welch's t-test が第一選択**になります。本書のデータも Normal 7 vs Tumor 8 とサンプル数が異なるため、Welch の方が適切です。

論文（Section 2.5）でも同様に Welch's t-test が使われており、以下の基準で有意差タンパク質を定義しています：

- **p < 0.05**（生の p値）
- **Fold change > 2 または < 0.5**（Log2 FC > 1 または < -1）

本書もこの基準に従います。

## コード

```python
def welch_ttest(df, sample_groups):
    """各タンパク質について Welch's t-test を実行。"""
    normal = sample_groups["Normal"]
    tumor = sample_groups["Tumor"]

    results = []
    for protein in df.index:
        normal_vals = df.loc[protein, normal].dropna()
        tumor_vals = df.loc[protein, tumor].dropna()

        # 有効値が2つ未満ではt検定できない
        if len(normal_vals) < 2 or len(tumor_vals) < 2:
            continue

        # Welchのt検定（equal_var=False）
        t_stat, p_value = stats.ttest_ind(tumor_vals, normal_vals, equal_var=False)

        # Log2 Fold Change（Tumor / Normal）
        log2_fc = tumor_vals.mean() - normal_vals.mean()  # Log2 スケールでは差 = log2 ratio

        results.append({
            "Protein": protein,
            "log2_fc": log2_fc,
            "p_value": p_value,
            "normal_mean": normal_vals.mean(),
            "tumor_mean": tumor_vals.mean(),
        })

    return pd.DataFrame(results).set_index("Protein")
```

### コード詳細

- **`stats.ttest_ind(..., equal_var=False)`**: scipy の独立2標本t検定。`equal_var=False` が Welch モード
- **`log2_fc = tumor_vals.mean() - normal_vals.mean()`**: 入力がすでに log2 スケールなので、引き算が log2 fold change になる
  - `log2(Tumor/Normal) = log2(Tumor) - log2(Normal)`
- **`dropna()`**: 欠損値（NaN）を除去してから検定に使う
- **`len(...) < 2`**: 各群で有効値が2つ以上ないと分散が計算できないため検定不能

## Fold Change の解釈

Log2 FC の値と生の fold change の対応：

| Log2 FC | Fold Change | 意味 |
|---------|-------------|------|
| +3 | 8 倍 | Tumor で 8倍高い |
| +2 | 4 倍 | Tumor で 4倍高い |
| +1 | 2 倍 | **閾値（Up-regulated）** |
| 0 | 1 倍 | 変化なし |
| -1 | 0.5 倍 | **閾値（Down-regulated）** |
| -2 | 0.25 倍 | Tumor で 1/4 |
| -3 | 0.125 倍 | Tumor で 1/8 |

論文の基準「Fold change > 2 or < 0.5」は Log2 FC に直すと **|log2_fc| > 1** です。

## 論文との差分の考察

| 指標 | 本書 | 論文 | 差が生じた理由 |
|------|------|------|---------------|
| 有意差タンパク質数 | 954 | 2,642 | 検定対象 (2,381 vs 10,329) の時点で約 4.3倍差 |
| Up / Down比 | 3.79 | 1.26 | sage は低発現タンパク質 (Down側) の検出が苦手 |
| サンプル数 | 15 | 32 | 統計パワーが小さいため閾値超えの本数が減る |

論文の結果を完全に再現しようとすれば、サンプル数と同定タンパク質数を揃える必要があります。しかしチュートリアル目的では、**「手順が同じで、生物学的パターンが再現される」** ことの方が重要です。本書でも「Normal/Tumor の差は明確に検出される」「PC1 寄与率はほぼ一致」「COSMIC の大腸がん関連遺伝子の重複は存在する」という本質は再現されています。
