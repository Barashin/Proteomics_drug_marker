# ProteomeXchangeからのデータ取得とmzMLへの変換

## ProteomeXchange とは

**ProteomeXchange** (https://www.proteomexchange.org/) は、世界中のプロテオミクス実験データを統一的に公開するコンソーシアムです。主要なリポジトリとして以下があります。

| リポジトリ | URL | 特徴 |
|-----------|-----|------|
| **PRIDE** | https://www.ebi.ac.uk/pride/ | 最大規模。EMBL-EBIが運営 |
| MassIVE | https://massive.ucsd.edu/ | UCSDが運営 |
| jPOST | https://jpostdb.org/ | 日本のリポジトリ |
| iProX | https://www.iprox.org/ | 中国のリポジトリ |

Toyota et al. 2025 のデータは **jPOST** に登録されています。論文の「Data Availability Statement」から Project ID を確認し、対応する rawファイルをダウンロードできます。

## Step 3-1-1: 論文のデータアクセッション番号を確認

論文の PDF 末尾または Supporting Information に、以下のような記述があります。

> The mass spectrometry proteomics data have been deposited to the ProteomeXchange Consortium via the jPOST partner repository with the dataset identifier PXD0xxxxx.

この `PXD` から始まるIDが ProteomeXchange の共通識別子です。

## Step 3-1-2: raw ファイルのダウンロード

ProteomeXchange のサイトに PXD ID を入力すると、リンク先の jPOST/PRIDE に遷移します。各データセットのページには `.raw` ファイル（Thermo装置の場合）、`.d` ファイル（Bruker）、または `.wiff`（SCIEX）といった装置生データが並んでいます。

```bash
# 例: wget で一括ダウンロード（URLは実際のリポジトリから取得）
wget -r -np -nH --cut-dirs=3 -A "*.raw" \
  ftp://ftp.pride.ebi.ac.uk/pride-archive/2025/08/PXD0xxxxx/
```

Toyota 論文のデータは合計で約 **27 GB** (32ファイル) あります。ネットワーク速度に応じて数十分〜数時間かかります。

## Step 3-1-3: raw → mzML 変換（ProteoWizard MSConvert）

Thermo の `.raw` ファイルは閉じた形式なので、下流解析のツールが読める **mzML** に変換する必要があります。業界標準ツールは **ProteoWizard の MSConvert** です。

| ツール | プラットフォーム | GUI / CLI | ライセンス |
|-------|----------------|----------|-----------|
| **MSConvert** (ProteoWizard) | Windows (推奨), Linux/Mac (Docker) | 両方 | Apache 2.0 |
| ThermoRawFileParser | クロスプラットフォーム (.NET) | CLI | Apache 2.0 |

### Windows での変換（最も確実な方法）

1. ProteoWizard の公式サイトから MSConvert GUI をダウンロード・インストール
2. MSConvert GUI を起動し、`.raw` ファイルをドラッグ＆ドロップ
3. **Output format** を `mzML` に設定
4. **Filters** に以下を追加：
   - `peakPicking true 1-`: MS1/MS2 を centroid化（sage等が要求）
   - `zeroSamples removeExtra`: ゼロ強度のデータポイントを除去
5. `Start` をクリック

### Mac/Linux での変換（Docker）

```bash
docker run -it --rm -e WINEDEBUG=-all \
  -v /path/to/raw/files:/data \
  chambm/pwiz-skyline-i-agree-to-the-vendor-licenses \
  wine msconvert /data/*.raw \
  --mzML \
  --filter "peakPicking true 1-" \
  --filter "zeroSamples removeExtra" \
  -o /data
```

### 変換時の重要パラメータ

- **`peakPicking true 1-`**: すべてのMS1/MS2レベルでピークピッキング（centroid化）を行います。sage、DIA-NN、OpenMS などの現代のDIA解析ツールは centroid 化されたデータを前提にしているため、**必須**の設定です。
- **`zeroSamples removeExtra`**: ピーク近傍の微小なゼロ強度点を除去してファイルサイズを削減します。

## 本書で使う mzML ファイルについて

本書のリポジトリには、論文のデータのうち **8患者分（15ファイル、約13 GB）** の mzML ファイルがすでに準備されています。サンプル数とファイルサイズを縮小しているため、読者は自分で raw→mzML 変換を行う必要はありません。
