# 論文化への道筋と発展的な拡張

## このパイプラインで論文を書く3つのアプローチ

本書のパイプラインは、大腸がんに限らず **あらゆる DIA-MS プロテオミクスデータ** に適用できる汎用的なものです。このパイプラインを使って自分の論文を書くための具体的な方針を3つ紹介します。

### アプローチ1: 別の疾患データに適用（最もおすすめ）

同じパイプラインを、**別の疾患の公開データ** に適用するアプローチです。

```
1. ProteomeXchange または PRIDE で別疾患の DIA-MS データを探す
2. mzML をダウンロード（または raw → mzML 変換）
3. 本書のパイプラインで解析
4. 疾患特異的なバイオマーカー候補を報告
```

**候補データ例**:

- 肝がん (HCC)、膵がん、乳がん、肺がんの DIA-MS データ
- 炎症性腸疾患 (IBD)、関節リウマチのプロテオミクスデータ
- パーキンソン病、アルツハイマー病の脳脊髄液プロテオミクス

**想定投稿先**:

| 誌名 | IF (2024) | 分野 |
|------|----------|------|
| Journal of Proteome Research | 4.0 | プロテオミクス |
| Proteomes (MDPI) | 3.0 | プロテオミクス |
| Proteomics Clinical Applications | 3.6 | 臨床プロテオミクス |
| Journal of Proteomics | 3.5 | 一般プロテオミクス |

### アプローチ2: 機械学習を追加

本論文は統計解析のみですが、**機械学習（Random Forest、XGBoost、LASSO）** を追加してバイオマーカーパネルを構築すれば新規性が高まります。

```
本パイプラインの差分発現結果
  → 特徴量選択（LASSO、Boruta、Recursive Feature Elimination）
  → 機械学習モデル構築（RandomForestClassifier、XGBClassifier）
  → ROC-AUC、PR-AUC で診断性能を評価
  → 独立コホートで検証（他公開データを使う）
```

**追加が必要なパッケージ**:

```bash
micromamba install -c conda-forge scikit-learn xgboost lightgbm shap -y
```

### アプローチ3: ツール比較の方法論論文

**sage、DIA-NN、FragPipe、OpenMS** を同じデータに適用して結果を比較し、「**商用クリアな sage パイプラインの妥当性**」を定量的に示す方法論論文を書けます。

```
同一データセットに対して:
  ① DIA-NN で解析（論文と同じツール）
  ② sage で解析（本書の方法）
  ③ FragPipe + MSFragger-DIA で解析
  ④ OpenMS + AlphaPeptDeep で解析
  → タンパク質同定数、定量再現性、FDR 推定の一致度を比較
  → それぞれの得手不得手とユースケース推奨を提示
```

**想定投稿先**: Journal of Proteome Research, Bioinformatics, BMC Bioinformatics

### 1. パスウェイ・エンリッチメント解析

差分発現タンパク質（本書では 954 個）を **GO、KEGG、Reactome** にマッピングして、どの生物学的経路が有意に濃縮しているかを調べます。

```python
import gseapy

# 上昇タンパク質の遺伝子リスト
up_genes = differential_proteins[differential_proteins["significant"] == "Up"].index.tolist()

# Enrichr への問い合わせ
enrichr = gseapy.enrichr(
    gene_list=up_genes,
    gene_sets=['KEGG_2021_Human', 'GO_Biological_Process_2023', 'Reactome_2022'],
    organism='Human',
    outdir='results/enrichr_output'
)
```
