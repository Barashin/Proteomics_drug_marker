# まえがき

本書は、Toyota et al. "Identification of Cancer-Associated Proteins in Colorectal Cancer Using Mass Spectrometry" (*Proteomes* 2025) のdry解析パイプラインを、**無料かつ商用利用可能なツールのみ**で再現する技術書です。

## 本書で学べること

- **DIA-MSプロテオミクス**の基本概念
- **sage-proteomics**（MITライセンス）を使ったタンパク質同定・定量
- **Pythonによる統計解析**（差分発現解析、PCA、クラスタリング）
- **COSMICデータベース**を使ったがん関連タンパク質の照合
- **ステージ別解析**（ANOVA、プロファイルプロット）

## 対象読者

- バイオインフォマティクス初心者（プログラミング未経験でもOK）
- プロテオミクスデータの解析に興味がある研究者・学生
- DIA-MSの論文を自分のデータで再現したいウェット研究者
- 論文のdry解析パートの仕組みを理解したい方

## 本書の特徴

1. **コピペで動く**: すべてのコードをそのままコピーして実行できます
2. **無料ツールのみ**: 有料ソフトウェア（Perseus等）はPython/Rで代替
3. **行ごとの解説**: コードの各行を丁寧に説明します
4. **エラー対処つき**: よくあるエラーと解決法を記載しています

## 動作環境

- macOS / Linux / Windows（WSL2）
- Python 3.11
- micromamba（パッケージマネージャ）
