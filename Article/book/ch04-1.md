# DIA解析ツールの比較とsageの選択

## 現代のDIA-MS解析ツール一覧

2025年時点で、library-free DIA 解析ができるツールは以下の通りです。

| # | ツール | 開発元 | ライセンス | library-free DIA | 深層学習ライブラリ予測 |
|---|-------|-------|-----------|:---:|:---:|
| 1 | **DIA-NN** | Demichev lab | **非営利・学術のみ無料** | ✅ | ✅（DeepLC系、内蔵） |
| 2 | **Spectronaut** | Biognosys | **商用（有料）** | ✅ | ✅ |
| 3 | **MSFragger-DIA** (FragPipe) | Nesvizhskii lab / UMich | **非営利・学術のみ無料** | ✅ | ❌ |
| 4 | **sage-proteomics** | Michael Lazear | **MIT** | ✅ | ❌（理論スペクトル） |
| 5 | **OpenMS + AlphaPeptDeep** | OpenMS Team + Mann lab | **BSD + Apache 2.0** | ✅ | ✅（外部連携） |
| 6 | **MaxQuant / MaxDIA** | Cox lab (MPI) | 非商用ライセンス（無料配布） | ✅ | ⚠ |

## ライセンスの落とし穴

プロテオミクス解析ツールのライセンスは、ソフトウェアの世界で一般的な OSS ライセンス（MIT、BSD、Apache）とは異なり、**「非営利・学術研究のみ無料」という制約**がかかっているものが多くあります。

### DIA-NN の場合

DIA-NN の GitHub リポジトリ (https://github.com/vdemichev/DiaNN) の LICENSE.txt には概ね以下のような条項が書かれています：

- **非営利・学術研究目的**での使用は自由
- **商用利用**（製薬企業の研究、受託解析サービス、書籍として解析結果を販売する行為など）は**別途ライセンス契約が必要**

学術論文の再現を個人的に行う分には問題ありませんが、本書のように **書籍として解析結果を含む形で販売する** 場合、厳密にはライセンス契約が必要になります。

### MSFragger (FragPipe) の場合

MSFragger も同様で、University of Michigan の技術移転オフィス (UMich Tech Transfer) との契約が商用利用時に必要です。FragPipe のラッパー自体はオープンソースですが、コア検索エンジンである MSFragger とその定量モジュール IonQuant がこの制約を受けます。

### Spectronaut の場合

完全な商用ソフトで、ライセンス費用は年間数千ドル以上。高機能ですが個人利用には非現実的です。

## 商用利用が完全にクリアな選択肢

上の表で商用利用に一切の制約がないのは以下です：

| ツール | ライセンス | 特徴 |
|-------|-----------|------|
| **sage-proteomics** | MIT | 単一バイナリ、Rust製、超高速、library-free DIA ネイティブ対応 |
| **OpenMS + AlphaPeptDeep** | BSD + Apache 2.0 | 複数ツールの連携が必要、セットアップ工数大 |

この2つのうち、**セットアップが圧倒的に簡単で、かつ商用完全クリア**という条件で選んだのが sage-proteomics です。

## sage-proteomics とは

- **開発者**: Michael Lazear (現在 BMS/独立研究者)
- **初版**: 2022年
- **主要論文**: Lazear MR. "Sage: An Open-Source Tool for Fast Proteomics Searching and Quantification at Scale." *J. Proteome Res.* 2023. DOI: 10.1021/acs.jproteome.3c00486
- **リポジトリ**: https://github.com/lazear/sage
- **ライセンス**: **MIT**
- **言語**: Rust（単一バイナリ、依存なし）

### sageの技術的特徴

| 特徴 | 説明 |
|------|------|
| 速度 | Rust製で極めて高速。本書の15ファイル（13GB）を **約4.5分** で解析 |
| library-free | FASTAファイルを渡すだけで in silico 酵素消化 → 理論スペクトル生成 → DIAマッチングを自動実行 |
| wide-window DIA | `wide_window: true` オプションで DIA の wide isolation window に対応 |
| LFQ定量 | 内蔵の `quant.lfq` モジュールで MS1-XIC ベースの定量を計算 |
| 出力 | `.tsv` または `.parquet`。Python/R で直接読める |
| プラットフォーム | Linux、macOS（Intel/Apple Silicon）、Windows |

### sageと DIA-NN の本質的な違い

| 比較項目 | sage | DIA-NN 1.8.x |
|---------|------|------------|
| 検索アルゴリズム | hyperscore (MSFragger系) | X!Tandem系スコア |
| スペクトルライブラリ | **理論スペクトル**（b/y イオンの質量だけ） | **深層学習予測**（強度と RTまで予測） |
| 定量 | MS1 XIC 統合 | MS1 XIC + MS2 fragment 補助 |
| Match Between Runs | 基本的に無効 | 標準的に有効 |
| GUI | なし（CLIのみ） | Windows GUI あり |
| 速度 | **最速** | 速い |

深層学習ライブラリ予測がないため、DIA-NN に比べて低存在量ペプチドの検出感度がやや劣ります。その代わりに**単一バイナリで外部依存なし、MIT ライセンスで完全に自由**という利点があります。

## sage のインストール

sage は bioconda チャネルから導入できます。第2章で作成した `crc-proteomics` 環境にインストールします。

```bash
# crc-proteomics 環境をアクティブにする
micromamba activate crc-proteomics

# sage-proteomics を bioconda からインストール
micromamba install -c bioconda -c conda-forge sage-proteomics -y

# バージョン確認
sage --version
```

期待される出力：

```
sage 0.14.6
```

### インストール失敗時の代替手段

bioconda で失敗した場合は、GitHub Releases から事前ビルドバイナリを直接ダウンロードできます：

```bash
# macOS Apple Silicon (M1/M2/M3/M4)
wget https://github.com/lazear/sage/releases/download/v0.14.7/sage-v0.14.7-aarch64-apple-darwin.tar.gz
tar xzf sage-v0.14.7-aarch64-apple-darwin.tar.gz
mv sage /usr/local/bin/
```

Linux x86_64 や Windows 向けのバイナリも同ページにあります。

## pymzml のインストール

mzML ファイルの事前検査（第3章で使用）のために pymzml も必要です。

```bash
micromamba install -c bioconda -c conda-forge pymzml -y
```

## ここまでのまとめ

- DIA 解析ツールは多種多様だが、**商用利用を考えるとライセンスの精査が必須**
- sage-proteomics は **MIT ライセンス**で、商用利用に制約なし
- bioconda から1コマンドでインストールできる
- 速度は DIA-NN と同等以上、Rust製で単一バイナリ
