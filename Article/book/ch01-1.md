# DIA-MSプロテオミクスとは

## プロテオミクスとは

**プロテオミクス（proteomics）**は、生体内のタンパク質を網羅的に解析する学問分野です。ゲノミクス（DNA）やトランスクリプトミクス（RNA）と並ぶ「オミクス」の一つですが、タンパク質は実際に機能する分子であるため、**疾患の状態をより直接的に反映**します。

```
DNA → RNA → タンパク質 → 機能
ゲノミクス  トランスクリプトミクス  プロテオミクス
                                    ↑ ここを見る
```

## 質量分析（Mass Spectrometry）とは

質量分析は、分子の**質量/電荷比（m/z）**を測定する技術です。プロテオミクスでは以下の流れでタンパク質を同定・定量します：

```
組織サンプル
  → タンパク質抽出
  → トリプシン消化（ペプチドに分解）
  → 液体クロマトグラフィー（LC）で分離
  → 質量分析（MS/MS）で測定
  → データ解析ソフトで同定・定量
```

## DDA vs DIA

質量分析には大きく2つのデータ取得方式があります。

### DDA（Data-Dependent Acquisition）

従来の方式。**強度の高い上位Nイオンだけ**を選択してフラグメンテーション。

- メリット: 同定の信頼性が高い
- デメリット: 検出にムラがある（毎回違うペプチドが選ばれる）

### DIA（Data-Independent Acquisition）

本論文で使用。**全イオンを網羅的に**フラグメンテーション。

- メリット: 再現性が高い、低発現タンパク質も検出しやすい
- デメリット: データが複雑で高度な解析ソフトが必要

| 特徴 | DDA | DIA |
|------|-----|-----|
| 選択方式 | 上位Nイオンを選択 | 全質量範囲を網羅 |
| 再現性 | 低い（ランダム性あり） | **高い** |
| 検出深度 | 中程度 | **高い** |
| データサイズ | 小さい | 大きい |
| 解析難易度 | 低い | 高い（要専用ソフト） |

## sage-proteomics とは

**sage-proteomics** は、Rust 製の超高速 DIA 解析エンジンです。論文では DIA-NN v1.8.1 が使用されていますが、DIA-NN は**商用利用に有料ライセンスが必要**なため、本書では **MIT ライセンスの sage** で代替します。

- **開発者:** Michael Lazear
- **ライセンス:** **MIT**（無料、**商用利用完全OK**）
- **特徴:** 単一バイナリ、library-free DIA ネイティブ対応、DIA-NN 同等以上の速度
- **論文:** Lazear MR. *J. Proteome Res.* 2023. DOI: 10.1021/acs.jproteome.3c00486
- **GitHub:** https://github.com/lazear/sage

sage は bioconda から 1 コマンドでインストールでき（`micromamba install -c bioconda sage-proteomics`）、本書のデータ（15ファイル、13GB）を **約4.5分** で解析できます。詳細は第4章を参照してください。

## Perseusの代替について

論文ではPerseus v1.6.15.0を統計解析に使用していますが、Perseusは**MaxQuantライセンスに基づいており商用利用に制限**があります。

本書では、Perseusの機能を**Pythonの科学計算ライブラリ**で完全に代替します：

| Perseusの機能 | Python代替 | パッケージ |
|-------------|----------|----------|
| Log2変換 | `np.log2()` | numpy |
| 欠損値補完 | カスタム関数 | numpy |
| PCA | `PCA()` | scikit-learn |
| 階層的クラスタリング | `linkage()` | scipy |
| ヒートマップ | `clustermap()` | seaborn |
| Welch's t-test | `ttest_ind()` | scipy |
| One-way ANOVA | `f_oneway()` | scipy |
| FDR補正 | `multipletests()` | statsmodels |
