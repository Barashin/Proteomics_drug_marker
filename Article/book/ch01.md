## 論文の概要

**Toyota N, Konno R, Iwata S, et al.**
"Identification of Cancer-Associated Proteins in Colorectal Cancer Using Mass Spectrometry."
*Proteomes* 2025; 13(3):38.

### 何をした研究か？

大腸がん（CRC）患者16人から採取した**腫瘍組織**と**隣接正常組織**のタンパク質を、DIA-MS（データ非依存型質量分析）という最新の手法で網羅的に解析した研究です。

### 主な発見

1. **10,329タンパク質を同定** — 腫瘍と正常組織から網羅的にタンパク質を定量
2. **531のがん関連タンパク質** — COSMICデータベースと照合し、がんに関連するタンパク質を特定
3. **48のCRC特異的タンパク質** — 大腸がんに特に関連する48タンパク質を同定
4. **ステージ進行に伴うタンパク質変動** — 疾患の進行に伴って一貫して増減するタンパク質クラスターを発見

### なぜこの論文をフォローするのか？

| 理由 | 説明 |
|------|------|
| **パイプラインがシンプル** | DIA-MS → 統計解析 → COSMIC照合の明確な3ステップ |
| **データが公開** | ProteomeXchange (PXD058672) で全データ利用可能 |
| **無料ツールで再現可能** | sage (MIT) + Python で論文の解析を商用可能な形で再現できる |
| **拡張余地が大きい** | 別の疾患データに同じパイプラインを適用して論文化できる |
| **初心者に最適** | 機械学習を使わないシンプルな統計解析が中心 |
